This dashboard visualizes usage activity on the ADARV platform, broken into weekly buckets (Friday–Thursday, including zero-activity weeks so trends aren't misleading). It covers two main areas:

User engagement — total login events each week alongside the split between brand-new users and returning users.
Contribution activity — visits to the contribute page, individual dataset edit/view actions, and how many distinct outbreak datasets were touched.

A summary section compares the most recent 7 days against the prior 7 days across five key metrics (unique users, new users, total logins, contribute-page visits, dataset touch events), with percentage change and mini trend charts for each.

Built as a single self-contained HTML file using Chart.js (loaded via CDN), so it requires no backend or build step — it can be hosted as-is on GitHub Pages.
